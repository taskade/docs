# Media AI Chat

---

## Overview

With Media AI Chat, you can **ask the Taskade AI about your files, projects and media**. Upload documents, images or videos, or connect a project. Then ask questions, get the key facts and write new content from your media.

> **Taskade Genesis connection:** Each file that you upload to a Genesis app or use in Media AI Chat goes to the Media library of your workspace. The file adds to your [Workspace DNA](../genesis/how-genesis-works.md). Your future apps and agents can use it.

---

## Chat Methods

### Method 1: Chat with Projects

Ask questions about a Taskade project in plain language:

1. Open a project in Taskade.
2. In the top-right corner, click the **chat button** 💬.
3. At the top of the chat box, choose **Ask Project** from the drop-down.
4. Ask a question about the project.

The AI uses the data of the project to answer. Only you can see your chats in **Ask Project**.

**Example queries:**

| Query | What AI Returns |
|---|---|
| "Summarize this project" | A short summary of all tasks, notes and status |
| "What tasks are overdue?" | A list of late items with details |
| "Who is assigned the most tasks?" | The workload of each team member |
| "Generate a status report" | A formatted report from the project data |

### Method 2: Chat with Projects & Team

Talk with the AI and your team in the same chat:

1. Open a project. In the top-right corner, click the **chat button** 💬.
2. At the top of the chat box, choose **Taskade AI** from the drop-down.
3. Ask the AI a question.

All members of the project can see this shared chat. Team members can ask more questions, add context or give the AI a new direction.

> **Tip:** Use this chat when your team studies data together. The AI gives the data, and your team discusses it and decides.

### Method 3: Chat with Attachments

Upload a file into a chat, and the AI reads it at once:

1. Open an AI chat: Taskade EVE, an agent or a project chat.
2. Drag a file into the chat, or click the attachment button.
3. Ask a question about the file.

The AI reads the file and answers. A chat accepts these files:

- Images (JPG, PNG, GIF, WebP) and PDFs, up to 20 MB each
- TXT, MD, CSV and JSON files, up to 200 KB each

**Example interactions:**

| File and query | AI Response |
|---|---|
| **PDF report**: "What are the key findings?" | A summary of the main points and conclusions |
| **CSV data**: "What trends do you see?" | Patterns and key facts in the data |
| **Image**: "Describe what you see" | A description of the image |
| **Product CSV**: "Which products have the highest margin?" | Exact answers from the data |

### Method 4: Chat in Media Manager

See all media of your workspace in one place:

1. In your workspace, open the **Media** tab.
2. Find the file in the list of uploaded files, generated images and other media.
3. Move the pointer over the file and click 🤖 **Ask AI**.
4. Type your question in the pop-up.

> **Note:** Media shows the files that you upload into a project. In a project, you can also move the pointer over an attachment and click 🤖 **Ask AI**.

## Supported Media Types

This table is for files in the Media tab, agent knowledge and links that you paste. A chat attachment can only be one of the types in [Method 3](#method-3-chat-with-attachments).

| Media Type | Formats | AI Capabilities |
|---|---|---|
| **Documents** | PDF, DOCX, TXT, MD, PPTX, XLSX, CSV, EPUB | Read the full text, summarize, answer questions, extract data |
| **Images** | PNG, JPG, GIF, SVG, WebP | Describe the image, read the content, read text in the image (OCR) |
| **Video** | YouTube URLs (via transcript) | Read the transcript, find key points, answer questions |
| **Web Content** | URLs, blog posts, articles | Read the content, summarize, compare |
| **Spreadsheets** | XLSX, CSV, Google Sheets | Study the data, find trends, write reports |
| **Presentations** | PPTX | Read the slides, make an outline |
| **Social** | Tweets, Reddit posts, news articles | Find the tone, summarize, write a reply |

## Use Cases

| Use Case | Example prompt |
|---|---|
| **Document analysis**: upload a report and ask questions | "What are the Q3 revenue figures from this financial report?" |
| **Data exploration**: upload a CSV and ask for patterns | "Which customer segment has the highest churn rate in this data?" |
| **Content extraction**: upload a PDF and get structured data | "Extract all contact information from this business card scan" |
| **Image understanding**: upload a screenshot and get a description | "What UI elements are shown in this mockup?" |
| **Meeting prep**: ask about project notes before a meeting | "Summarize the open items and blockers from last sprint's project" |
| **Competitive analysis**: add competitor URLs and compare | "Compare the features listed on these two competitor pages" |
| **Knowledge building**: upload training files and test yourself | "Create 5 quiz questions from this training document" |
| **Report generation**: ask about data and get a formatted report | "Create a monthly report from this spreadsheet data" |

## Media & Workspace DNA

Each time you use media, your workspace learns more:

| Media Action | DNA Impact |
|---|---|
| Upload files to a Genesis app | The files go to the Media library. Future apps and agent knowledge can use them. |
| Generate images in chat | Taskade saves the images to Media. All apps can use them again. |
| Upload agent knowledge | Taskade indexes the knowledge for agent answers. AI answers improve in the workspace. |
| Analyze documents | The results help future app builds. |
| Chat with project data | Taskade EVE learns the patterns of your workspace. |

> **Cross-link:** You can use files from Media AI Chat as [Genesis Context](../genesis/adding-context.md), as [Agent Knowledge](./agent-knowledge.md) and as data sources for [Automations](../automation/README.md).
