## What's New:

### Four New Read Tools on the Hosted MCP Server

The hosted Taskade MCP server (beta) at `https://www.taskade.com/mcp` adds four read tools for id-addressed access — no virtual-filesystem paths needed:

| Tool | What it returns |
|------|-----------------|
| `list_projects` | Projects in a workspace, as structured JSON (id, name) |
| `read_project` | A project's full contents — task tree with assignees, dates, tags — as a structured text document |
| `list_agents` | The AI agents in a workspace (id, name) |
| `list_automations` | The automation flows in a workspace (id, name) |

All four take a `spaceId` (get it from `list_spaces`) and require workspace membership on a plan with MCP access. They complement the existing `list_spaces` / `inspect_space` / `write_file` tools. See [Hosted Taskade MCP](../../../apis-living-system-development/genesis-app-mcp.md).

***

### Free Plan: Full-Depth First Builds

Auto now gives Free-plan workspaces a serious first build: your first Genesis app build runs at full **Reasoning** depth, and follow-up edit turns run at **Thinking** depth — the same capability tiers paid plans use. Welcome credits (1,000 when you verify your account, plus 5,000 when you start your first app build) are sized to cover one complete build. See [TSK-1 Model Tiers](../../../genesis-living-system-builder/ai-features/tsk-1-model-tiers.md).
