## What's New:

### Fix: Optional Select Fields Accept Empty Form Submissions

Flow form triggers no longer reject submissions that leave an optional **Select** (or multi-select) field untouched — previously an untouched dropdown could fail validation and return a 400 for the whole form. The same fix applies to generated apps, so they can save records with optional Select fields left blank. Required fields still validate exactly as before. See [AI Forms](../../../genesis-living-system-builder/automation/ai-forms.md).
