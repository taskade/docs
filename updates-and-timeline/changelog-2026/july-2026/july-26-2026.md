## What's New:

### Generated Apps: File Uploads into Automation Flows, End to End

Apps built with Genesis can now accept **file uploads** and pass them into automation flows end to end. Large files upload reliably, uploaded files land in your workspace's media library where downstream steps can read them, and generated flows handle every document type through a single **Convert File to Text** step. Combined with the new [OCR fallback](july-25-2026.md), a generated app can take a scanned PDF upload and extract its text in one flow.

***

## Improvements & Fixes:

* Flow AI actions (Ask AI, Generate, Respond) now respond based solely on your configured prompt, fixing occasional off-target output.
* Generated-app list rows fall back to the row's text for titles instead of showing "Untitled".
* Flow validation now flags misconfigured steps that previously ran but silently did nothing, so you can fix or regenerate them.
* SAML SSO configuration now works on workspaces on the legacy Ultimate plan, and SSO setup errors surface the actual server message instead of a generic "Unknown error". See [Collaboration](../../../genesis-living-system-builder/workspaces/collaboration.md).
* General stability, performance, and reliability improvements.
