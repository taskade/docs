# Where to Find New Releases

Every new release is published at [**taskade.com/changelog**](https://www.taskade.com/changelog), one page per version. Follow the [RSS feed](https://www.taskade.com/changelog/feed.xml) to get each release as it ships. See [Latest Releases](latest-releases.md) for the other places to look.
